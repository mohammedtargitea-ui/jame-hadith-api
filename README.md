# جامع الحديث النبوي الشريف — واجهة برمجية

قاعدة موحدة مبنية على برنامج «جامع الحديث النبوي الشريف» من شبكة المدارس
الإسلامية (madarisweb.com)، نقل حرفي كامل: 405 كتب، منها 401 كتابًا مسندًا،
و521,566 حديثًا وأثرًا مشكولًا، و53,871 عنقود تخريج، و54,200 كيان مكررات،
و13,784 ترجمة راوٍ بـ53,571 حكم جرح وتعديل، و270,794 إسنادًا.

الخدمة الحية: https://jame-hadith-api.onrender.com
التوثيق التفاعلي: https://jame-hadith-api.onrender.com/docs

## المسارات — التوثيق الصحيح

| المسار | الوظيفة |
|---|---|
| `GET /` | بطاقة الخدمة |
| `GET /stats` | إحصاءات القاعدة |
| `GET /books` | قائمة الكتب |
| `GET /books/{book_id}?page=1&size=20&rtype=hadith` | تصفح كتاب |
| `GET /hadith/{rec_id}` | الحديث كاملًا: نصه وكتابه ورواته وأحكامه وتعليقات المحققين وعناقيده |
| `GET /takhrij/{rec_id}` | **نافذة التخريج عبر الكيانات**: مكررات الحديث عبر كل مصادر البرنامج |
| `GET /entity/{entity_id}` | كيان التخريج بأعضائه |
| `GET /cluster/{cluster_id}` | عنقود التخريج: نص الطرف + الروايات الأساسية والمرتبطة |
| `GET /narrator/{rowah_id}` | ترجمة الراوي + أحكام الجرح والتعديل |
| `GET /narrators/search?q=` | بحث الرواة |
| `GET /isnad/{asn_id}` | الإسناد المسلسل |
| `GET /hadith/{rec_id}/isnads` | سلسلة رواة الحديث بالترتيب |
| `GET /search?q=&kind=&book=&rtype=&page=&size=` | البحث الحر غير المتحسس للتشكيل |

## ملاحظات

- المعرف غير الموجود يعيد 404 — سلوك مقصود.
- البحث يقارن الكلمة كاملة؛ إن أعاد صفرًا فجرّب مشتقات اللفظ
  (ينتعل / انتعال / تنعل مثلًا).
- الخطة المجانية على رندر تنام بعد 15 دقيقة خمول وتصحو في نحو دقيقة
  مع أول طلب.

## التحديث مستقبلًا

1. ارفع نسخة `jama_hadith.sqlite` الجديدة إلى مستودع البيانات العام
   `MoChihab/jame-hadith-data` على هوغنغ (استبدال الملف).
2. حدّث رقم الحجم بالبايت في `Dockerfile` (سطر التحقق).
3. ارفع الملفات المتغيرة هنا، وسيعيد رندر البناء تلقائيًا.
